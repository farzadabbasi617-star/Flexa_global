# جدول‌های غریبه در دیتابیس

بررسی‌شده: ۲۰ آگوست ۲۰۲۶

دیتابیس Neon این پروژه **۹۴ جدول** دارد، ولی همهٔ آن‌ها متعلق به Gament نیستند.
چند سیستم دیگر — که کاربر تأیید کرده جدا و بی‌ربط‌اند — در همان دیتابیس نشسته‌اند.

این سند فقط **ثبت وضعیت** است. هیچ‌کدام از این جدول‌ها حذف نشده‌اند.

---

## چرا حذف نشدند

این جدول‌ها **ممکن است هنوز توسط بات‌های دیگر در حال استفاده باشند**. اینکه اپ Gament
به آن‌ها ارجاع نمی‌دهد ثابت نمی‌کند مرده‌اند — فقط ثابت می‌کند *این* اپ استفاده‌شان نمی‌کند.
`scraped_users` با ۲۵ هزار ردیف قطعاً محصول یک سیستم فعال بوده.

حذف چیزی که مالکش این کدبیس نیست، تصمیمی نیست که بدون تأیید صریح گرفته شود.

---

## فهرست

هیچ‌کدام از این‌ها در `src/` ارجاعی ندارند (بررسی‌شده با grep روی کل پوشه):

| جدول | ردیف | حجم | احتمالاً مال |
|---|---:|---:|---|
| `scraped_users` | ۲۴,۹۹۲ | 6.3 MB | بات ضد اسکرپ |
| `added_history_tbl` | ۱,۰۷۳ | 240 kB | بات adder |
| `leads_tbl` | ۲۸ | 96 kB | بات adder |
| `scanned_chats_tbl` | ۴۲ | 48 kB | بات ضد اسکرپ |
| `price_memory` | ۲۰ | 96 kB | تخمین‌گر قیمت |
| `config_tbl` | ۱۵ | 64 kB | بات adder |
| `saved_accounts_tbl` | ۱۲ | 88 kB | بات adder |
| `adder_limits_tbl` | ۱۲ | 64 kB | بات adder |
| `do_not_add_tbl` | ۶ | 80 kB | بات adder |
| `hbk_stories` | ۲ | 32 kB | HaghBaKie |
| `hbk_users` | ۱ | 32 kB | HaghBaKie |
| `bg_scan_state` | ۱ | 64 kB | بات ضد اسکرپ |
| `hbk_votes` | ۰ | 16 kB | HaghBaKie |
| `hbk_comments` | ۰ | 16 kB | HaghBaKie |

**مجموع: حدود ۷.۱ مگابایت از ۲۴ مگابایت کل دیتابیس.**

دو جدول (`saved_accounts_tbl` و `leads_tbl`) ستون `created_at` را به صورت
**عدد Unix timestamp** ذخیره می‌کنند، نه `timestamp` — یعنی از پروژه‌ای با
کانونشن متفاوت آمده‌اند. این خودش شاهد دیگری است که مال این کدبیس نیستند.

---

## آیا الان مشکل‌ساز است؟

**نه.** دیتابیس ۲۴ مگابایت از سقف ۵۱۲ مگابایت Neon است. این جدول‌ها فضا اشغال
می‌کنند ولی روی کارایی Gament اثری ندارند چون هیچ کوئری‌ای به آن‌ها نمی‌خورد.

تنها هزینهٔ واقعی: **بزرگ‌ترین جدول این دیتابیس دادهٔ این پروژه نیست.** موقع
`pg_dump` گرفتن یا مهاجرت به VPS، ۷ مگابایت دادهٔ بی‌ربط هم منتقل می‌شود.

---

## پیشنهاد برای زمان مهاجرت به VPS

بهترین فرصت برای جداکردن، همان لحظهٔ مهاجرت است:

```bash
# فقط جدول‌های Gament را منتقل کن
pg_dump "$NEON_URL" \
  --exclude-table=scraped_users \
  --exclude-table=added_history_tbl \
  --exclude-table=leads_tbl \
  --exclude-table=saved_accounts_tbl \
  --exclude-table=adder_limits_tbl \
  --exclude-table=do_not_add_tbl \
  --exclude-table=scanned_chats_tbl \
  --exclude-table=config_tbl \
  --exclude-table=projects_tbl \
  --exclude-table=bg_scan_state \
  --exclude-table='hbk_*' \
  > gament-only.sql
```

بعد Neon دست‌نخورده باقی می‌ماند و بات‌های دیگر بدون هیچ تغییری به کار خود ادامه
می‌دهند، در حالی که VPS فقط دادهٔ Gament را دارد.

⚠️ قبل از هر کاری روی این جدول‌ها، **از صاحب بات‌ها بپرس** — یعنی از خودت.
