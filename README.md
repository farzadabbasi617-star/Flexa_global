# Flexa Arena (Flexa Global)

**Flexa Arena** is a next-generation global esports and tournament platform built for competitive mobile and cross-platform gamers worldwide (CODM, Clash Royale, Fortnite, PUBG Mobile, etc.).

## 🌟 Key Features

- **Multi-Language Support (i18n):** Native support for English 🇬🇧, Arabic 🇸🇦, Turkish 🇹🇷, and expanding.
- **Crypto & Digital Payments:** Built-in support for USDT, TON (Telegram Open Network), and global payment gateways.
- **AI-Powered Judging & Match Verification:** Instant AI-driven result verification and dispute resolution.
- **Telegram Mini-App Ready:** One-click seamless tournament registration directly within Telegram WebApps.
- **Real-time Brackets & Leaderboards:** Single Elimination, Double Elimination, Round Robin, and Automated Ladders.

## 🛠️ Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4 + Framer Motion
- **Database:** PostgreSQL (Neon / Drizzle ORM)
- **Bot:** GramMY (Telegram Bot API)

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/farzadabbasi617-star/Flexa_global.git
cd Flexa_global

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
